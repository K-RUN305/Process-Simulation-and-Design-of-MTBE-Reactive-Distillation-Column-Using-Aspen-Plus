# MTBE-Reactive-Distillation-Column-Using-Aspen-Plus
Simulated and designed an MTBE reactive distillation column
Simulated and designed an MTBE reactive distillation column in Aspen Plus by integrating reaction kinetics with separation, optimizing operating conditions and column parameters to improve MTBE conversion, product purity, and process efficiency.
Simulated MTBE Production via reactive distillation in ASPEN Plus, analyzing both kinetic and equilibrium limited regimes for process optimization.Achieved more than 95% MTBE purity by tuning reflux ratio and tray configuration, and identified reaction hotspots (9th- 11th stages) for efficient coloumn design.
